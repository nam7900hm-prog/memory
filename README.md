# 학습 기억법 — 방법을 바꾸면 미래가 보인다

수학의 정의·정리·용어를 **연상 이미지 기억 → 기억의 궁전 → 두문자어 만들기** 세 가지 기억법으로, **기초 → 중급 → 고급** 단계에 따라 이해하며 외우는 웹 앱입니다.

- 설치나 빌드 과정 없이 HTML·CSS·JS 파일만으로 동작합니다.
- 학생은 태블릿으로 화면의 **QR 코드**를 찍어 바로 입장합니다. (작게 / 크게 / 숨기기)
- 학생이 만든 장면·궁전·두문자어는 각자의 기기(브라우저)에 저장됩니다.

## 구성

**처음 화면 → 기초 · 중급 · 고급 → 기억법 고르기 → 훈련**

- 단계 화면 맨 위 **먼저 보기**: 같은 본문을 ① 본문 → ② 요점 정리 → ③ 기억법(연상 이미지 / 기억의 궁전 / 두문자어 / 3가지 함께)으로 바꾸는 과정
- 훈련 하나 = **사용법 먼저 보기 → ① 본문 읽기(밑줄) → ② 요점 정리 → ③ 기억법 적용 → ④ 꺼내기(채점)** × 본문 2개
- 기억의 궁전 장소: 내 몸 · 우리 교실 · 내 방 · 요일 · 우리 학교
- 예시는 학생이 먼저 직접 만든 뒤에만 열립니다.

## 연상 기억 수업 (처음 화면 '들어가기')

- **파트 1 · 연상 이미지 체험**: 단어를 하나씩 보여 주고 사라지게 → 1차 16칸 → 연상으로 연결(학생이 직접 적기) → 30초 되새기기 → 최종 16칸, 점수 비교
- **파트 2 · 공부하는 방법**: 역사 「임진왜란」으로 본문 → 밑줄 → 요점 5개 → 두문자어 → 연상 → 궁전(내 몸) → 연결 → 꺼내기. 장면 12개, 장면마다 아래에 선생님 설명 대본

## 학습 원칙

화면 위쪽 색 띠: **✏️ 연필로 요점 정리 → 🧠 머리에 저장 → 💡 꺼내기**

## 내용 고치기

`js/data.js`의 `LEVELS`(먼저 보기), `TRAINING`(훈련 본문·요점·예시), `CLASS_SETS`(파트 1 단어), `METHOD_LESSON`(파트 2 장면)을 고치면 됩니다.

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   디자인
js/qr.js        QR 코드 생성기 (외부 라이브러리 없음)
js/data.js      학습 내용 (여기만 고치면 내용이 바뀝니다)
js/app.js       화면 이동, 문제, 저장, QR 도크
```

## GitHub → Vercel로 올리기

1. GitHub에서 새 저장소를 만듭니다. (예: `memory-app`)
2. 이 폴더 안의 파일을 **그대로** 업로드합니다. (`index.html`이 저장소 맨 위에 있어야 합니다)
   - 웹에서 올릴 때: 저장소 → **Add file → Upload files** → 파일과 폴더를 끌어다 놓기 → **Commit changes**
3. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인합니다.
4. **Add New… → Project** → 방금 만든 저장소의 **Import**를 누릅니다.
5. Framework Preset은 **Other**로 두고, 다른 설정은 바꾸지 않은 채 **Deploy**를 누릅니다.
6. 1분쯤 지나면 `https://프로젝트이름.vercel.app` 주소가 생깁니다.

이후 GitHub에서 파일을 고치면 Vercel에 자동으로 다시 배포됩니다.

## 수업에서 QR 사용하기

- 앱을 열면 오른쪽 아래에 **작은 QR**이 보입니다.
- 교실 화면이나 전자칠판에서는 **크게**를 누르면 화면 가득 QR이 나옵니다. 학생들이 태블릿 카메라로 찍으면 바로 입장합니다.
- 수업 중에는 **숨기기**를 누르세요. 오른쪽 아래의 `QR 접속` 버튼을 누르면 다시 나타납니다.
- QR에는 **지금 열려 있는 주소**가 자동으로 들어갑니다. 다른 주소를 넣고 싶으면 크게 보기에서 **접속 주소 직접 입력**을 누르세요.
  (예: 특정 단원 주소 `https://…vercel.app/#/t/palace`로 바로 보내기)
